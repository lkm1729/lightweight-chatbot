Easy Chatbox 使用说明
======================================================================

这是一个本地运行的聊天客户端，支持 Anthropic / OpenAI Chat / OpenAI Responses
/ Gemini 四套接口协议，可以同时挂多个供应商（官方站或中转站）。


一、怎么启动
----------------------------------------------------------------------

双击本文件夹里的：

    Easy-Chatbox 启动.exe

首次启动约 4~8 秒（程序要先解压自身），之后会弹出聊天窗口，直接用即可。

* 如果安全软件弹窗询问是否允许联网 / 监听端口，请选择「允许」。程序只在本机
  127.0.0.1 上开一个本地端口给自己的界面用，不对外网开放。
* 关闭窗口即退出，不留后台进程。


二、第一次使用要先填 API 配置
----------------------------------------------------------------------

程序本身不含任何 API 额度，需要填你自己的密钥：

1. 点界面里的「设置」；
2. 选一套协议（比如 Anthropic Messages），新增一个供应商；
3. 填 Base URL 与 API Key，再添加你要用的模型；
4. 保存后回到主界面，在顶部下拉框选择模型，即可开始对话。

支持联网搜索（Tavily / Brave / Serper / SearXNG / Exa），同样在设置里填密钥。


三、你的数据存在哪
----------------------------------------------------------------------

全部在 exe 同级的 data 目录里，程序不往系统其他地方写东西：

    data/config.json        API 配置
    data/chats.db           对话历史
    data/attachments/       上传过的附件
    data/startup.log        启动日志（出问题时看这个）

因此整个文件夹可以直接拷到 U 盘或另一台电脑，历史和配置都跟着走。
不想用了直接删掉整个文件夹即可，没有注册表残留。

【注意】data/config.json 里的 API Key 是明文保存的。
分享这个文件夹给别人之前，请先删掉 config.json，否则等于把密钥一起送出去。


四、常见问题
----------------------------------------------------------------------

窗口打开后一片空白 / 提示无法打开内置窗口
    说明系统缺少 WebView2 运行时（Win11 自带，部分 Win10 需要补装）。
    程序会自动改用默认浏览器打开，功能一样可用。
    想要独立窗口，请安装微软官方的 WebView2 运行时：
    https://developer.microsoft.com/microsoft-edge/webview2/

提示「本地服务启动超时」
    通常是安全软件拦了程序在本机监听端口。把本程序加入信任列表后重试。

对话报错、连不上模型
    先在设置里点「测试连通性」，确认 Base URL 与 API Key 填对了。
    用中转站时注意 Base URL 结尾要不要带 /v1，按你的中转站文档填。

想换个位置放数据
    设置环境变量 CHATBOX_DATA_DIR 指向你想用的目录即可。
