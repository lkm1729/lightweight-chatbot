    开始一段对话

    先在「设置」里添加供应商与模型，再从输入框右侧选择模型。

    供应商与模型设置

    四个协议下各可挂多个供应商（官方站或中转站）。Base URL 只需填基础地址 （https://api.example.com 或 https://api.example.com/v1）， 版本段与协议路径会自动补全；若中转站路径特殊，可在结尾加 # 锁定完整端点。 模型的底层 ID 是发给上游的名字，显示名只用于界面。

    联网搜索配置

    开启联网搜索按钮后，会先调用搜索 API 获取资料，再将结果作为上下文发给模型。 支持 Tavily、Brave、Serper、SearXNG、Exa 五种协议。
